# Small DS — Tokens

Design tokens generated from Figma. Published as `@small-ds/tokens`.

## Rules

**1. Never invent a token.** If something looks missing, *ask Bastian first* —
in Figma or in code. This is a standing instruction and the easiest thing to get
wrong here, because the system is deliberately small and a plausible-looking gap
is usually intentional.

**2. Figma is the source of truth**, file key `DABmspHvLwmzYjMrFBjVQW`. Code
never invents a value; it mirrors what the file already holds. `tokens/` is
generated by `scripts/transform.mjs` from `scripts/figma-dump.json` — edit
neither by hand.

**3. Components never reach past the semantic layer.** Tier 1 (`color/neutral/*`,
`color/utility/*`, `spacing/*`, `typography/*`) exists only for Tier 2 to point
at. The exception is `motion/*`, which has no Tier 2 layer by design — see the
README for why.

## Things that will waste your time if you don't know them

- **The Figma plan is Pro, not Enterprise, so the Variables REST API is
  unavailable.** `GET /v1/files/:key/variables/local` returns 403. Extraction
  goes through the Figma MCP `use_figma` bridge — see `scripts/figma-extract.js`.
- **Tier 1 is not published to the Figma library**, so `search_design_system`
  cannot see it and will return empty for `neutral`, `spacing`, `motion` and
  friends. That is not a bug — it is what makes rule 3 enforceable at the library
  boundary. Enumerate *local* variables instead.
- **`dictionary.allTokens` inside a Style Dictionary format is the filtered set**
  when the file has a `filter`, which breaks reference lookups. The dark block is
  therefore emitted directly in `config/style-dictionary.mjs` rather than via a
  second SD pass.
- **Type inference is by path segment, not prefix.** Tier 3 nests the group
  deeper (`button/primary/color/background/default`), so a `^color/` test
  mistypes every component colour token.

## Commands

```sh
npm run build    # transform tokens/ from the dump, then build dist/
npm run verify   # assert nothing was lost and the alias chain is intact
```

Always run `npm run verify` after touching the build. It catches the failure
that matters: a broken alias chain, which looks fine in light mode and silently
kills dark mode.

## Units

Typography `rem`, layout `px`, `font-weight` unitless, durations `ms`.
Controls must use `min-height`, never `height` — see README.
